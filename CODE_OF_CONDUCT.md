# Code of Conduct

## Our pledge

Everyone participating in this project — issues, pull requests, discussions — deserves respect. Be kind, assume good faith, and keep critique focused on code and ideas, not people.

## Standards

**Encouraged:** patience with newcomers, clear bug reports, constructive feedback, and respecting privacy (never post other people's data).

**Not tolerated:** harassment, personal attacks, discriminatory language, doxxing, spam, or advertising.

## Enforcement

Violations can be reported via GitHub's "Report content" controls or a private message to the maintainer. Maintainers may remove content and ban repeat offenders.

*This is a short-form conduct guide; the project may adopt the full Contributor Covenant as the community grows.*
